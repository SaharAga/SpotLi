Fixed UI problems found in a walkthrough of the app. The page no longer
scrolls behind open dialogs: the shared scroll lock now locks `<html>` as well
as `<body>`. The package card's "⋮" menu no longer hides items under the
header, the tab bar or the Feedback button, and Escape now closes both it and
the "+" add sheet. Pickup Points now scrolls as one area on phones. Pale
status and PIN text is readable in light mode. Long package titles are no
longer squeezed by their status badge. The admin dashboard is now full-screen
on phones, with a compact header, tabs that fit, a fixed height, a chart
legend, honest empty states when cloud data fails to load, localized labels
and dates, and a confirm step before clearing the local buffer.
